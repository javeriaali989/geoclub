# GeoClub — The Global Industrial Network

The professional B2B marketplace and industrial networking platform for energy and industrial sectors.

## Features
- **Utility Top Bar**: Verified business indicator, opportunity posting link, and language switcher.
- **Sticky Header**: Responsive navigation, brand mark, sign-in & join actions, and mobile menu drawer.
- **Hero Section**: Global industrial search bar with category filtering, popular search keywords, and verified professional network counter.
- **Metrics Strip**: Verified statistics across companies, countries, products/services, and deal volume.
- **Industries Grid**: 6 industrial verticals with supplier counters and icon badges.
- **Marketplace Solutions**: Interactive category filtering (*Products, Services, Software, All*) with verified solution cards and direct RFQ request modal.
- **Featured Companies**: Verified supplier profiles with company credentials and locations.
- **How It Works**: 3-step operational workflow (*Build presence, Find fit, Connect & grow*).
- **Open Opportunities**: Live tenders, RFQs, and partnership listings with posting workflow.
- **Global Reach**: 142-country network overview with country directories.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports.

## Tech Stack
- HTML5
- Vanilla CSS3
- JavaScript (ES Modules)
- Vite
